Python Variables and Data Types

A variable stores a value in Python. Common data types include int, float, str, bool, list, tuple, set, and dict.

Python Loops

Python supports for loops and while loops. A for loop iterates over items in a sequence, while a while loop repeats as long as a condition is true.

Python Functions

A function is a reusable block of code defined using the def keyword. Functions can accept parameters and return values.

Python Exception Handling

Python uses try, except, else, and finally to handle exceptions and prevent unexpected errors from stopping a program.

Python OOP

A class defines the structure of objects. An object is an instance of a class. Inheritance allows a class to reuse features of another class. Encapsulation groups data and methods, while polymorphism allows a common interface to have different implementations.

Python OOP Concepts with Examples

A class is a blueprint for creating objects. An object is an instance of a class.

Example:
class Student:
    def __init__(self, name):
        self.name = name

student = Student("Vasanthi")
print(student.name)

Output: Vasanthi

1. Encapsulation
Encapsulation combines data and methods inside a class and controls access to internal data.

2. Inheritance
Inheritance allows one class to reuse properties and methods from another class.

Example:
class Animal:
    def speak(self):
        print("Animal makes a sound")

class Dog(Animal):
    pass

dog = Dog()
dog.speak()

Output: Animal makes a sound

3. Polymorphism
Polymorphism allows different classes to use the same method name with different behaviors.

4. Abstraction
Abstraction hides implementation details and exposes only the necessary functionality.

5. Constructor
The __init__ method initializes an object when it is created.

Python Collections: List, Tuple, Set, and Dictionary

List:
A list is an ordered, mutable collection that allows duplicate values.
Example: numbers = [10, 20, 20, 30]

Tuple:
A tuple is an ordered, immutable collection that allows duplicate values.
Example: numbers = (10, 20, 20, 30)

Set:
A set stores unique values and does not guarantee a fixed order.
Example: numbers = {10, 20, 30}

Dictionary:
A dictionary stores data as key-value pairs.
Example: student = {"name": "Vasanthi", "age": 22}
